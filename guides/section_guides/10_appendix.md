# APPENDIX

**Purpose:** Supporting evidence that would interrupt the main narrative.

**Default exhibits** (Roman numerals, in this order when present):
- **Exhibit I: Bulls vs Bears.** 3–4 bullets each, dense and numbered like the body text.
- **Exhibit II: Street Discussion Summary.** Only if a public sell-side view or earnings-call Q&A is available and cited. Format: "<Source> | PT: $X | Rating: Y", then short bolded run-in paragraphs by theme. Never fabricate analyst views. If none are available, omit this exhibit.
- **Exhibit III: Exit Strategy.** The horizon and 2–3 trackable metrics with thresholds that would trigger an exit or a re-rate (e.g. "~300 bps of EBITDA margin expansion").
- **Company-specific exhibits:** KPI tables, contract schedules, benchmark tables, sensitivity analyses (e.g. "Reels Engagement EPS Impact"), each with a Source line.
